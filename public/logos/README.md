# Service logos

Put the official logo files here, using these exact names:

- `paypoint.png`
- `payzone.png`
- `national-lottery.png`

As an agent you can get approved logo artwork from each provider's retailer
portal / marketing support (PayPoint, Payzone, Allwyn for The National Lottery).
PNG or SVG with a transparent or white background works best (about 600px wide).
If you use another name or format, update the "Logo file name" in /admin.

Until a file is added, the website shows the service name in text instead.
